From one leg to a whole robot

The Stage A leg explorer solved one leg. This is the next step: a full six-legged robot. Every leg runs the same closed-form inverse kinematics — pick where each foot should go, and the solver returns the three joint angles that put it there. The MuJoCo runner in this folder does exactly this, eighteen joints at a time.

Drag the robot to orbit the camera. Move the sliders to change its stance. Press Walk to watch the alternating tripod gait.

This is the runner, file by file

Everything you just played with is the Python in this folder. The interactive view and the MuJoCo simulation share the very same logic.

config.py — the one geometry file: link lengths, the six leg mounts, joint limits, the stance and gait numbers. Every slider above edits a value that lives here.
hexapod_ik.py — the closed-form solver. leg_ik() runs once per leg, six times a frame, exactly as it does here in the browser.
hexapod_model.py — builds the MuJoCo model: a round trunk, six 3-DOF legs, eighteen joints.
run.py — the runner. It picks the foot targets (a stance, or this moving gait), solves the IK, and drives the joints. python run.py opens the real physics viewer; python run.py --check proves it.

Where this fits. Stage A (due 28 May) is this: the per-leg solver wrapped in MuJoCo so the whole robot stands and walks. Because the model and the solver both read config.py, swapping in the real PhantomX hardware later is a one-file change. Stage B then builds proper gaits on top.
