# The Physical AI Tutorial

Four chapters, each readable in ~15 minutes, each ending with a
runnable Colab notebook and a key-takeaways box.

1. **[LLM AI vs Physical AI](01-llm-vs-physical-ai.md)** — what
   changes when intelligence gets a body.
2. **[Legs and Fingers: Nature's Engineering](02-legs-and-fingers.md)**
   — six legs, eight legs, two legs, ten fingers: why each design
   exists and which one a beginner should build.
3. **[MuJoCo Without Tears](03-mujoco-intuition.md)** — how a physics
   simulator actually works, with zero hand-waving.
4. **[Reinforcement Learning, Intuitively](04-rl-intuition.md)** —
   states, actions, rewards, PPO, and sim-to-real, all through one
   hexapod example.

!!! tip "How to read"
    Chapters build on each other but each stands alone. If you only
    care about "how do robots learn to walk?", jump straight to
    [Chapter 4](04-rl-intuition.md).
