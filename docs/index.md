# Robo-Greeno: Learn Physical AI with a Six-Legged Robot

**Physical AI** is artificial intelligence that has to obey gravity.
This site teaches it from zero, using a real open-source project: a
swarm of hexapod (six-legged) spider robots built for agricultural
fields, simulated in MuJoCo and trained with reinforcement learning —
on hardware cheap enough for students (ESP32 + Raspberry Pi).

## The project behind the tutorial

Robo-Greeno is part of the [KamaTech](https://kamatech.org.il) OSS
On-the-Job Training program (2026). Six participants build hexapod
kinematics, tripod/wave/ripple gaits, IMU stabilization, and RL
locomotion — all open source, all reproducible on a free Colab GPU.
See the [repository](https://github.com/KamaTechOrg/robo-greeno-data-a)
for the 10-week plan, code, and notebooks.
